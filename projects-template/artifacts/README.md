# Artifacts — __PROJECT_NAME__

Folder ini digunakan untuk menyimpan deliverable dan hasil pengerjaan project.

Path penuh: `projects-rogue/__PROJECT_ID__/artifacts/{folder}/`

| Folder | Kegunaan |
|--------|----------|
| `src/` | Kode sumber utama (Source code) |
| `build/` | Hasil build, kompilasi, atau transpilation |
| `assets/` | Aset pendukung (images, 3d, design, media) |
| `output/` | Hasil generate akhir (render, laporan final, data hasil) |

Dokumentasi E2E tetap di `../docs/` (srs, planning, …).
