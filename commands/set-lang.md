# Set Language

Set bahasa chat **persisten** di project root `LANGMODE.md`.

Minta user (atau ambil dari argumen): `id` (Bahasa Indonesia) atau `en` (English).

Lalu tulis/overwrite `LANGMODE.md` (project root) dengan template dari `ai-agents-rogue/templates/LANGMODE.md`, judul:

- `# Active chat language: id` atau
- `# Active chat language: en`

Konfirmasi singkat ke user bahasa aktif. Cakupan: **balasan chat saja** (bukan kode/dokumentasi).
Detail: `ai-agents-rogue/LANGMODES.md`.

Tidak menjalankan E2E atau implementasi — hanya mengganti bahasa chat.
