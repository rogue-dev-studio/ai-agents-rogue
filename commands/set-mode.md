# Set Mode

Set mode kerja **persisten** di project root `WORKMODE.md`.

Minta user (atau ambil dari argumen): `e2e` atau `manual`.

Lalu tulis/overwrite `WORKMODE.md` (project root) dengan template dari `ai-agents-rogue/templates/WORKMODE.md`, judul:

- `# Active work mode: e2e` atau
- `# Active work mode: manual`

Konfirmasi singkat ke user mode aktif + ringkas perilaku.
Detail: `ai-agents-rogue/WORKMODES.md`.

Tidak menjalankan E2E atau implementasi — hanya mengganti mode.
