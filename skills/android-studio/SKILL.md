# Android Studio

**Level: max.**

## Summary

Android development tools including Gradle, ADB, and AVD management.

## When to use

- Android app development, build, test, and debugging
- Android Studio is installed and configured

## Procedure

1. **Setup** — Ensure Android SDK is configured.
2. **Build** — Use `./gradlew` for builds.
3. **Test** — Use ADB for device/emulator interaction.
4. **Plan** — Document build/test steps in `project/{id}/docs/tasks/`.

## DoD

- [ ] Android SDK available
- [ ] Build/Test successful
- [ ] No secrets in git
