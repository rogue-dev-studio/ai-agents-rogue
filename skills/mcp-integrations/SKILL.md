# MCP Integrations (Canonical)

**Level: max.** Aliases: `context7-mcp`, `jira-mcp`, `linear-mcp`, `excalidraw-mcp`, `pal-mcp-server`.

## Procedure

1. Daftar MCP yang diizinkan tim (jangan pasang semua).
2. Auth OAuth/token di secret store; scope minimum.
3. Uji 3 tool calls emas per server.
4. Scaffold server baru hanya jika gap jelas (scaffold MCP server).
5. Dokumentasikan di project notes: server → guna → owner.

## DoD

- [ ] Allowlist MCP
- [ ] Smoke tools OK
- [ ] Token tidak di git
