# Anti-Slop UI & Visual (antislop-ui)

Prevent "cookie-cutter" AI interfaces and generic visual patterns. Ensure UI is context-aware, varied, and purposeful.

## Objective
Avoid the "AI-Generated Look"—generic gradients, uniform cards, and lifeless layouts.

## Visual Guardrails

### 1. Layout & Composition
- **Avoid Uniformity**: Stop making every section a 3-column grid of identical cards. Use asymmetrical layouts or varied content blocks.
- **Purposeful Spacing**: Avoid the "default-bootstrap" look. Use intentional whitespace and typographic hierarchy instead of relying on generic containers.
- **Contextual Layouts**: Ensure the layout reflects the data's importance, not just a template's structure.

### 2. Color & Aesthetics
- **Ban Generic Gradients**: Stop using the "Purple-to-Blue" AI gradient. Use colors based on brand identity or psychological context.
- **Contrast & Depth**: Avoid flat, colorless "gray-on-white" interfaces. Use subtle shadows and depth only where they provide affordance.
- **Visual Variety**: Mix component types (e.g., a list, a detail view, and a summary card) instead of a repetitive list of the same component.

### 3. Motion & Feedback
- **Meaningful Motion**: Avoid generic "fade-in" on everything. Use motion to guide the user's eye or indicate state changes.
- **Micro-interactions**: Ensure every interaction has a distinct, non-generic feedback state.

## Quality Gate
UI is "Slop" if:
- It looks like a generic SaaS landing page from 2023.
- It relies entirely on default component library styles without customization.
- The visual hierarchy is flat and predictable.
