# Active chat language: id

Valid values: `id` | `en`

- `id` — balasan chat AI dalam Bahasa Indonesia (default)
- `en` — AI chat replies in English

Change the title line to switch language, or use `/set-lang` / chat ("bahasa inggris" / "bahasa indonesia").

Scope: **chat replies only** (percakapan dengan AI). Code, identifiers, dan dokumentasi/artifact mengikuti konvensi masing-masing — tidak dipaksa oleh file ini.

See `ai-agents-rogue/LANGMODES.md`.
