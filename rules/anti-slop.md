# Anti-Slop Orchestration Rule

This rule ensures that all outputs generated by AI Agents Rogue are filtered through the appropriate anti-slop skills to maintain human-grade quality.

## Trigger Mechanism

The AI Orchestrator MUST automatically activate the corresponding anti-slop skills based on the output medium:

| Output Medium | Trigger Condition | Required Skill(s) |
| :--- | :--- | :--- |
| **General Prose** | Any text generation, summaries, or chat responses | `antislop` |
| **Copywriting** | Headlines, CTAs, Articles, Marketing text, Email | `antislop` + `antislop-copywriting` |
| **Frontend/UI** | HTML, CSS, React/Vue components, Design specs | `antislop-ui` + `antislop-human` + `antislop-layoutmobile` |
| **Source Code** | Logic implementation, Refactoring, Documentation | `antislop` + `antislop-code` |
| **Visuals** | Image prompts, Video scripts, Storyboards | `antislop-visual` |
| **Audio** | TTS prompts, Podcast scripts, Music cues | `antislop-audio` |

## Execution Workflow

1. **Detection**: Identify the output medium of the current task.
2. **Activation**: Explicitly load the required anti-slop skills into the context.
3. **Generation**: Generate the content following the skill's guardrails.
4. **Verification**: Perform a "Slop Check" against the Quality Gate defined in the active skill.
5. **Refinement**: If "Slop" is detected, rewrite the output before presenting it to the user.

## Quality Gate (Global)
No output shall be delivered if it contains more than two "AI cliché" words (e.g., *delve, tapestry, pivotal*) or follows a predictable "Intro $\rightarrow$ List $\rightarrow$ Conclusion" robotic structure.
