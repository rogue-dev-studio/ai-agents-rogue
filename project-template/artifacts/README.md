# Artifacts — __PROJECT_NAME__

Deliverable non-dokumentasi (kode prototype, gambar, 3D, desain, media) **wajib** masuk ke sini, bukan di root repo sembarangan.

Path penuh: `project/__PROJECT_ID__/artifacts/{kategori}/`

| Kategori | Folder | Contoh |
|----------|--------|--------|
| Kode / prototype | `code/` | script, mini-app, generated source |
| Gambar / raster | `images/` | PNG/JPG dari ComfyUI, Photoshop, export |
| 3D | `3d/` | `.blend`, FBX/GLB, render stills |
| Desain vektor / UI export | `design/` | AI/SVG/PDF dari Illustrator, design tokens export |
| Media AV | `media/` | video/audio (FFmpeg, dll.) |
| Data / notebook out | `data/` | CSV, notebook outputs |
| Lainnya | `other/` | hanya jika tidak cocok di atas |

Dokumentasi E2E tetap di `../docs/` (srs, planning, …).

Baca `PROJECT.md` aktif di root workspace untuk `{id}` yang dipakai.
